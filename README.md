# DSA Fundamentals (.NET 10)

C# .NET 10 — Data Structures & Algorithms examples and exercises.

This repository contains small example projects and notes for learning common data structures and algorithms in C#.

Contents
- List/          - examples for List<T>
- Array/         - array examples
- LinkedList/    - linked list implementations
- Stack/         - stack examples
- Queue/         - queue examples
- Algorithms/    - sorting and searching implementations
- Tests/         - unit tests (xUnit)

How to run
1. Open the solution file in Visual Studio 2026.
2. Build the solution and run projects from the IDE or use dotnet CLI:
   dotnet build
   dotnet run --project ./List
