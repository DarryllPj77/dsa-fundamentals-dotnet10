# DSA.Fundamentals (.NET 10)

C# .NET 10 Data Structures & Algorithms examples and exercises.

## Included examples

- `Lists`
- `Arrays`
- `LinkedList`
- `Stack`
- `Queue`
- `Algorithms` (sorting + searching)

## Project structure

- `DSA.Fundamentals/` - Console app with example implementations
- `DSA.Fundamentals.Tests/` - xUnit unit tests
- `DSA.Fundamentals.slnx` - Solution file

## Quick usage

```bash
dotnet restore DSA.Fundamentals.slnx
dotnet run --project DSA.Fundamentals/DSA.Fundamentals.csproj
dotnet test DSA.Fundamentals.slnx
```
